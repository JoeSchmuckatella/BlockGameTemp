Version Release Notes:

 - Re-did the chunk meshing to use a custom buffer geometry and shader material
   rather than Three.js InstancedMeshes. This reduced the memory usage by about
   75% (on Chromium), allowing for future world expansion.
 - Fixed a bug that allowed the player to fall 1 chunk below the bottom of the
   world.
 - Made the F.O.V. slider functional.
 - Removed the draw distance slider, as it is not currently functional.
 - Stopped the pickaxe from clipping through blocks.
 - Reduced the C.P.U. usage when the game is paused.
 - Put the items in the hotbar in a more intuitive order.
 - Fixed a bug preventing saving on Firefox.
 - Improved saving ergonomics on Chromium-based browsers using the File System
   Access API.
 - If the "Save & Leave" button is pressed, but the save is cancelled, the game
   will no longer go to the loading screen and can be continued like normal.
 - Changed the freecam down button from Ctrl to Shift to prevent unwanted
   actions (such as saving the page with Ctrl+S or closing the window with
   Ctrl+W).
 - Fixed the back button in the main menu.
 - Added release notes.
